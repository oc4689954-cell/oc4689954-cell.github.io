Privacy Policy

herosWar Shorts · last updated 23 November 2026

herosWar Shorts is a private tool used only by the owner of the YouTube channel @herosWar to publish and measure that channel's own videos. It has no other users.

What data it accesses

Through the owner's own Google sign-in, and only for the owner's channel, it uses YouTube API Services to:

  • upload videos, captions and the channel's own comment (YouTube Data API);
  • read the channel's own videos and their status (YouTube Data API);
  • read the channel's own analytics reports, such as views, watch time and estimated revenue (YouTube Analytics API).

It does not access viewers' personal data, other channels, or any Google data beyond these.

How the data is used and stored

  • The data is used only to publish the owner's approved videos and to show the owner how they perform.
  • The sign-in token and the analytics numbers are stored on the owner's own computer. They are not sent to any server run by this tool, and they are not sold, shared or used for advertising.
  • Analytics snapshots are kept for as long as the owner keeps the project, to compare videos over time. The owner can delete them at any time.

herosWar Shorts' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be withdrawn at any time on the Google security settings page, security.google.com/settings/security/permissions. When access is revoked, the stored token stops working.

YouTube and Google

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Contact

Questions about this policy: contact the channel through youtube.com/@heroswar.
