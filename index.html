herosWar Shorts

The publishing tool behind the YouTube channel @herosWar: short, animated true stories from the World Wars.

What it is

herosWar Shorts is a private, single-user tool. It is not offered to the public and has no sign-up. The channel owner uses it to put their own animated Shorts on their own YouTube channel.

What it does with YouTube

  • Uploads a Short to the owner's channel, with its title, description and captions, only after the owner has approved that exact video and publish time.
  • Checks that the uploaded video was processed and published as scheduled.
  • Reads the channel's own YouTube Analytics (views, watch time, retention) so the owner can see how each Short did.
  • Posts the channel's own first comment on a published Short.

It uses the YouTube Data API and the YouTube Analytics API through the owner's own Google sign-in. It does not access any other channel or any viewer's data.
